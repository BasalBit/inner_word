The Writer
==========

A writing app for macOS. Everything in it can be done from the keyboard, and
everything can be done with the mouse.


Install
-------

1. Drag "The Writer" onto the "Applications" folder in this window.
2. Eject this disk image.


The first launch is blocked. That is expected.
----------------------------------------------

This build is not signed with an Apple developer certificate and is not
notarised by Apple, so macOS refuses to open it the first time. You have to
approve it once. After that it opens like any other app.

Option A: System Settings

1. Open The Writer from the Applications folder. macOS shows a message like
   "Apple could not verify "The Writer" is free of malware that may harm your
   Mac or compromise your privacy." Click Done. Do not click Move to Trash.
2. Open System Settings, then Privacy & Security.
3. Scroll down to the Security section. It says that "The Writer" was blocked
   to protect your Mac. Click Open Anyway. (The button stays there for about
   an hour after the blocked launch. If it is gone, repeat step 1.)
4. Confirm with Open Anyway, then enter your password or use Touch ID.

On macOS 14 and earlier you can instead Control-click the app in the
Applications folder, choose Open, and click Open in the dialog. On macOS 15
and later that shortcut no longer works; use the steps above.

Option B: Terminal

After dragging the app to Applications, open Terminal and run:

    xattr -dr com.apple.quarantine "/Applications/The Writer.app"

This removes the "downloaded from the internet" mark from the app. It then
opens normally with no warning.


If macOS says the app "is damaged and can't be opened"
-----------------------------------------------------

It is the same block with a different message. Use Option B.


Requirements
------------

macOS 10.15.7 or later on an Intel Mac, macOS 11 or later on a Mac with Apple
silicon. The name of the disk image says which kind of Mac it is for:
"arm64" is Apple silicon, "x86_64" is Intel, "universal" runs on both.


Finding your way
----------------

Right-click anything to see what you can do with it: the text, a link, a
comment, a document or a folder in the library on the left, the title above
the text, the counts at the bottom of the window. Select some text with the
mouse and a small format bar comes up above it (bold, italic, highlight,
link, comment and more); it can be switched off in the settings. The menu bar
at the top of the screen has every command with its key beside it.
Help > Keyboard Shortcuts lists all the keys, and Help > Welcome Document
opens a short introduction.

From the keyboard, Control-Return opens the same menus as a right-click, and
so does Shift-F10.


Your own keys
-------------

Every keyboard shortcut can be changed. The Writer > Keyboard Shortcuts...
(Command-/) lists all of them, grouped by where they work; type a name or a
key to find one. Press Return on a row (or click its key) and then the key
you want: the list says whether it is free, whether another command has it,
or why it cannot be used (a plain letter where you type text, a key macOS
keeps for itself), and you confirm. A command can have a second key or
none, and a command that has no key can be given one. Menus, hints and the
menu bar show your keys at once.

The rows you changed are marked and show what the default was; "Changed
Only" lists just those. A single command goes back to its default from its
row, everything with Reset All (also in The Writer menu, in case a change
went wrong). Export writes all keys to a file you can read, edit, keep or
take to another Mac (the keys of the assistant are in it too, also on a
Mac that has no assistant); Import reads such a file and shows what it
would change before anything changes, and says what is wrong with an entry
it cannot take. Your keys are stored with your library.

A few keys are not shortcuts and stay as they are: the keys of Vim mode; the
"/" that opens the insert menu while you type, and Tab, which takes its marked
row; the keys inside an open right-click menu (the arrows, Return, Escape and
the letters that jump to an item); and what a click does with a key held
(Command-click opens a link, Shift-click extends the selection, Control-click
is a right-click). With Vim mode on, Vim sees a key in the text before any
shortcut does: a shortcut without Command on a key that Vim uses does not run
in Normal mode, and the list tells you when you choose such a key. While a
right-click menu is open, a shortcut without Command does nothing.

If you ever take away a key you needed, nothing is lost: every command is
still in the menu bar and in the right-click menus, the list works with the
mouse alone, and The Writer > Reset All Keyboard Shortcuts... puts every key
back.


Zoom, and the size of a page
----------------------------

The text can be shown larger or smaller without changing it: sizes stay what
they are, nothing counts as edited, and an export is the same. By default
Command-+ zooms in, Command-- zooms out and Shift-Command-0 goes back to
100 % (like every key, these can be changed under Keyboard Shortcuts). With
the mouse: the percentage at the bottom right of the window opens the list of
sizes, and Command with the scroll wheel or a pinch on the trackpad zooms
around the pointer. The View menu has all of it. The window around the text
does not zoom.

Page view (by default Option-Command-P) shows the text on sheets of paper. At
100 % one point of the document is one point of the screen, as in Pages and
TextEdit; on today's displays that is about half the size of real paper. So
a page you have not zoomed yet opens as large as the paper itself, or as wide
as the window when that is narrower. "Life Size" in the zoom list is the size
of the paper on the display the window is on, "Fit Width" fills the window
and "Fit Page" shows one whole sheet. "Automatic" is what a page opens at
(as wide as the window, but not larger than paper): it is checked in the
list while it holds, and choosing it forgets the zoom you gave page view.
A sheet that is wider than the window scrolls sideways with two fingers, or
with Shift and the scroll wheel. The flowing column and page view each
remember their own zoom, and the same words stand on the same pages at
every zoom.


Fonts
-----

The settings (by default Command-,) have two font rows: "Font" under "New
documents" and under "This document". Return, Space or a click on the row
opens a list of every font on your Mac, each name in its own face; type to
narrow it down. The Left and Right arrows step through the fonts without
opening the list. A document written on another Mac keeps a font that is
missing here: the row says that it is not on this Mac, and another face
stands in for it until you choose one. For part of a text, select it and
pick a font with Command-T (by default) or Format > Font... .


Spelling
--------

The Writer marks misspelled words with a wavy red line as you write, using
the spell checker of your Mac (the same one Mail and Notes use; The Writer
brings no dictionary of its own). Right-click a marked word for suggestions,
or to teach your Mac the word (Learn Spelling: it is then known in your
other apps too) or to let it pass in this document until you close it
(Ignore Spelling). Command-; goes to the next marked word and
Shift-Command-; to the previous one. Code is not checked.

The language is found by itself, paragraph by paragraph. To check in one
language only, choose it in the settings (Command-,) under "Spelling
language", or for a single document in the same window under "This
document". The languages on offer are those of your Mac. A text in a
language your Mac has no dictionary for gets many marks: switch "Check
spelling while typing" off in the settings, or under Edit > Spelling.

If The Writer says that it is already open, another copy of it is running
with your library (for example an older copy that was not quit). Switch to
that copy, or quit it and open The Writer again. Two copies never work on one
library at the same time, so that neither overwrites what the other wrote.

If you are replacing an earlier preview build: quit the old copy before you
open this one. The preview does not take part in that check, so the two
could otherwise have your library open together.


The assistant
-------------

If Claude Code is installed on your Mac and you are signed in to it, The
Writer has an assistant that runs on it. Without Claude Code there is no
assistant, and nothing of it is shown; the settings say so in one line.

Command-J asks about the text you have selected, in a small chat right at
the selection: another word, a tighter sentence, a paragraph in another
tone. With nothing selected it is a plain question. Command-3 opens a
longer chat beside the text, which knows the whole document as it is now;
with "Add" you give it other documents and folders of your library to look
things up in. Each document keeps its own conversation.

The assistant advises and you apply. Every answer has buttons that put it
into the text (Replace Selection, Insert Below, Insert at Caret) or copy it,
and Command-Z takes it back. It never changes a document by itself.

What you ask goes to Anthropic through your own Claude Code sign-in, and
every message counts against your Claude Code plan. The small chat sends
your question and the selected text. The longer chat sends your messages,
the open document and what the assistant reads from your library. Nothing
is sent before you send a message. The Writer does not use your coding
setup in Claude Code (project instructions, hooks, skills, other tools) and
leaves nothing in its history.

The model and the effort are chosen in each chat. The switch that turns the
assistant off is in the settings (Command-,) under "Assistant". If a chat
says you are not signed in: open Terminal, run "claude" and sign in there,
then press Check Again.


Agents
------

The AI agents that run on your Mac (Claude Code, Codex, Gemini CLI and
others) can work with your library: find and read documents, create and edit
them, file them in folders, leave comments for you to go through, export.
They do it through a command line tool that comes inside the app:

    /Applications/The Writer.app/Contents/MacOS/writer

Agents can read at any time, and they can change things at any time too.
While The Writer is closed the tool writes to the library itself. While The
Writer is open the tool hands each change to the app, and the app makes it:
between two of your key presses, after saving whatever you have typed, so
nothing of yours is lost and nothing of the agent's is. A change to the
document you have open appears in the text where it belongs, and your caret
and your selection stay where they are. A note at the bottom of the window
says who changed what (for example: Claude changed "Chapter 2"), with an
Undo button. Undo in the Edit menu takes the agent's change out the same
way: it is one step, on top of your own typing. For a change to a document
that is not the open one the note has an Open button instead, and several
changes in a row are one note that counts them. The Writer menu has "Undo
Last Change by an Agent" and "Go to Last Change by an Agent" for the
keyboard; both are in the command palette too.

Before an agent changes the text of a document a version of it is kept:
File > Version History lists it with its reason ("Before an edit by Claude")
and brings it back. What an agent deletes goes to the trash. Comments an
agent leaves show up in the comments of the document under the agent's name.

If you would rather have agents wait until the app is closed, switch "Agents
can make changes while The Writer is open" off in The Writer > Agents... .
While the app is open they can then only read, and to change something they
are told to ask you to switch it on again, or to quit the app.

The Writer > Agents... (Option-Command-A) shows the tool, has that switch,
installs the skill that tells your agents about the tool, and lists the
command that adds The Writer's MCP server to each of them. Nothing is
installed anywhere until you press a button there, and The Writer does not
edit the configuration of any agent.

If an agent reports that macOS does not let it run the tool, the app still
carries the "downloaded from the internet" mark (see above: the tool is not
notarised either). Run the command of Option B once; it covers the tool too.


Your documents
--------------

The Writer keeps your library in

    ~/Library/Application Support/The Writer

Removing the app does not remove your documents. Back up that folder to keep
a copy of them.
